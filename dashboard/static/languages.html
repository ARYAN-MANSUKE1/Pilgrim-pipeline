Languages

One place for the whole site's language setup. Add a language here — its ACF content/audio/title fields, the nav menu, and the footer/header text all follow from this, no Elementor or menu editing.

Add a language

Pick from the languages Sarvam can actually generate audio for — this guarantees translation and audio both work, with no chance of a typo'd code. (Full list, verified against Sarvam's own API docs: Hindi, Bengali, English, Gujarati, Kannada, Malayalam, Marathi, Odia, Punjabi, Tamil, Telugu.)

Need a language not on this list? Add it manually — translation will still work, but Sarvam cannot generate audio for it; leave Audio off when processing temples in it.

Current languages

Toggle any box and hit Save on that row to change it — turning off ACF fields hides that language's Content/Audio/Title fields from the temple editor (its saved data is untouched and comes back the moment you turn it back on). Turning off Nav/chrome drops it from the nav menu and footer/header text. Turning off Visible just hides it from the site's language dropdown. To fully retire a language, turn all three off.
